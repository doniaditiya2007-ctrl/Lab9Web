MULAI DARI SINI

1. Baca file MULAI_DARI_SINI.md.
2. Salin folder Lab9Web ke C:\xampp\htdocs\Lab9Web.
3. Jalankan Apache dan MySQL di XAMPP.
4. Klik dua kali IMPORT_DATABASE_CMD.bat untuk impor database tanpa phpMyAdmin.
5. Buka http://localhost/Lab9Web/ di Microsoft Edge.
6. Ikuti panduan untuk menguji template, function, routing, dan CRUD.

Project ini belum otomatis menjadi bukti praktikum. Screenshot harus diambil dari hasil asli di laptop.
